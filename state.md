Tracks the current status of this project. Updated after every change (see CLAUDE.md) — this file should always reflect what's actually true right now, not what's planned or hoped for.

## Status
Nuxt dev server runs cleanly; homepage, stories, about, contact, and story detail pages verified. Hero illustration reworked, all UI icons migrated from emoji to Lucide, and an OpenRouter-powered AI story authoring tool (`/studio`) is live and tested end-to-end (generate → refine → publish). ## Known Issues
- Pre-existing (not introduced by recent changes): `<NuxtRouteAnnouncer />` in `app.vue` triggers a "Hydration completed but contains mismatches" console warning on every route. Content renders correctly; this is a cosmetic console warning only. Not investigated further as out of scope for the icon-migration work.

(The filesystem/serverless limitation previously noted here is now resolved — publishing writes to Supabase, which works on read-only hosts.)
