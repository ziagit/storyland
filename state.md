## Decisions
- [2026-09-16] Generation lives in `kidstory-api`, not in the Nuxt app, because the owner's model has to run in a container of its own (Python + llama.cpp) and Vercel functions can't host it; the Nuxt side just calls `POST /stories/generate`. Chose a **separate model Space** over loading the model inside the API container so the API image stays small, a slow generation can't starve API workers, and the model is reusable elsewhere. Chose llama.cpp + Q8_0 GGUF over `transformers` on CPU for speed (roughly 15–20 tok/s vs 2–4 on the free 2-vCPU tier).
