## Known Issues
- Pre-existing (not introduced by recent changes): `<NuxtRouteAnnouncer />` in `app.vue` triggers a "Hydration completed but contains mismatches" console warning on every route. Content renders correctly; this is a cosmetic console warning only. Not investigated further as out of scope for the icon-migration work.
- `/studio` has no authentication — anyone who finds/guesses the URL on a deployed instance could generate and publish stories. Fine for local use; needs auth before any public deploy. (The filesystem/serverless limitation previously noted here is now resolved — publishing writes to Supabase, which works on read-only hosts.)
- `/api/admin/generate-audio` and `/api/admin/backfill-audio` have no authentication either, same caveat as `/studio` — anyone who finds the URL on a deployed instance could trigger TTS jobs, burning through the owner's small daily ZeroGPU quota. Acceptable for local/single-owner use; needs auth before any public deploy, same as the existing `/studio` issue above.
- The Hugging Face Space's default speaker (`"Vivian"`, from the model card's example) has not been confirmed as an appropriate English children's-storytelling voice — the model card's own example usage is Chinese-oriented. Worth checking the model's actual documented speaker list once the Space is running, and adjusting `DEFAULT_SPEAKER` in `app.py` if needed.
- The Space itself is public, so strangers can technically call its Gradio API with no token at all — capped at a shared 2-minutes/day anonymous quota (small blast radius, but not zero). Accepted tradeoff of the free-ZeroGPU approach; a paid/private-Space setup would avoid this entirely.
- `server/utils/tts.ts`'s handling of the Gradio API's audio output (expects `result.data[0].url`, then fetches that URL for the WAV bytes) is based on reading the `@gradio/client` v2.5.0 source/types, not a live test against a running Space — there was no real Space to test against yet. This needs to be verified against the first real `/api/admin/generate-audio` call once the owner's Space exists, and may need a small adjustment if the actual response shape differs.
